# Contract: Baked Wash Textures

`yarn washes` (in `src/KCC.Web`) runs `Features/Bloom/generateWashes.ts`, which writes the textures into
`Features/Styles/Torn/Washes/` and `Features/Styles/Torn/Washes.css`, deleting any stale texture. Nobody edits either
by hand (FR-013). `bakeWashes.test.ts` diffs both against the generator by pixels.

## Files

| File | Size | Encoding | Content |
|---|---|---|---|
| `wash-chalk.png` | 128 x 128, 1 texel per CSS px | 4-bit indexed, 16 alpha levels in `tRNS`, adaptive row filters | `(blur₁(m) + .5) / 1.5` with `m` = strokes × tooth, stitched |
| `wash-blob-0.png` to `wash-blob-7.png` | 90 x 90, 6 CSS px per texel at the 480 px reference | as above | the displaced, blurred first-ink profile on the blob's ellipse, in a box with 6% margin per side |

## `Washes.css`

```css
/* GENERATED by `yarn washes` ... */
@layer components {
  .kcc-wash {
    --wash-span: 1.12;
    --wash-gain: 1.5;
    --wash-chalk: url("./Washes/wash-chalk.png");
    --wash-blob-0: url("./Washes/wash-blob-0.png");
    /* … to --wash-blob-7 */
  }
}
```

## Invariants the tests hold

- Committed CSS and textures equal the generator's, by pixels; no texture more or less.
- All textures together under 16,000 B (the `image_bytes` ceiling is 17,014 B, research R6); no `data:` URI.
- The chalk tile: every alpha in [.3, 1]; mean within .02 of .748; the wrap rows and columns differ from their
  neighbours by no more than 1.25 times the tile's mean neighbour difference; row and column means each within ±.01 of
  the tile mean (the bake subtracts each row's and column's deviation from the mean before quantising, so a low row
  does not repeat as a stripe every 128 px).
- Each blob: alpha 1 at its ellipse's centre; 0 on every texel of the texture's edge; eight distinct blobs; no darker
  ring (FR-002): along each of 64 rays from the ellipse centre to the texture's edge, the alpha never rises by more
  than one 4-bit level (1/15) over the highest alpha nearer the centre on that ray.
- `BLOB_COUNT` equals `WASH_BLOBS` in `washes.ts`; `--wash-span` equals the bake's span.
- `BLOB_SHAPES` is exported from `Features/Bloom/blobShapes.ts`, with its seeded source and no Node import, with each
  blob's ellipse centre and radii as content-box fractions; the bake draws each blob on it, the planner centres the
  second ink from it (rendering contract), and each blob's alpha is 1 at that centre.
- `washTextures.ts` exports `WASH_CHALK_FILE` (`wash-chalk.png`) in place of `WASH_GRAIN_FILE`.
- `isWashTexture` matches `wash-chalk.png` and `wash-blob-<n>.png` only, so the client build keeps them as files and
  `Layout.cshtml` preloads them (`assets/wash-*.png`).
- `contrast.test.ts` reads `--wash-gain` from `Washes.css`.
